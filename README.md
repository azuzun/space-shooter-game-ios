# space-shooter-game-ios

**Status: Under development**

A 2D arcade space shooter for iOS, built with Swift and SpriteKit. Pilot a spaceship, fire at incoming enemies, and earn points with each successful hit. This project explores touch-based gameplay, physics contact detection, sprite animation, and audio integration in a native iOS game.

## Current features

- Horizontal spaceship movement using drag gestures.
- Tap-to-fire laser projectiles with sound effects.
- Continuous enemy spawning with randomized flight paths.
- Physics-based contact detection between the player, enemies, and projectiles.
- Explosion animations and sound effects.
- On-screen score tracking.
- Player movement constrained to the visible game area.

## Technology

- **Language:** Swift
- **Game framework:** SpriteKit
- **App framework:** UIKit
- **Development environment:** Xcode
- **Platform:** iOS

## Getting started

1. Clone this repository and open `space-shooter-game-ios.xcodeproj` in Xcode.
2. Select the `space-shooter-game-ios` scheme and an available iPhone simulator.
3. Build and run the project.
4. To run on a physical device, select your own development team under **Signing & Capabilities** and use a unique bundle identifier.

## Controls

- **Drag horizontally** to move the spaceship.
- **Tap** to fire a projectile.

## Development status

The project is under active development and is not yet a finished release. Core movement, shooting, enemy spawning, scoring, and contact effects are implemented. The game-over flow, restart controls, difficulty progression, and further gameplay polish remain areas for future development.
